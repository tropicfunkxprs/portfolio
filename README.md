## 🌞 Overview

**Tropic Funkxprs** is a Borneo-born live band based in Kuala Lumpur, founded by **Khairul S.** and **Alfian Ahmad**.  
Their signature sound blends *tropical funk, soul, and pop* — uniting island rhythm with city groove.

This site serves as the **official portfolio reference (2023–2025)** — showcasing verified performances, collaborations, and professional profiles for press, event organizers, and brand partners.
